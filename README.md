# AI代码安全沙盒 - 产品规划

## 产品定位
为开发者提供AI生成代码的安全审查和风险检测，防止"删库跑路"等AI代码安全事故。

## 目标用户
- 主要用户群体：使用AI编程工具的开发者、技术负责人、DevOps团队
- 用户痛点：AI生成的代码可能包含删除文件、网络调用等危险操作
- 使用场景：AI生成代码后粘贴检测、CI/CD集成自动审查

## 核心功能
按优先级排列，最多5个核心功能：
1. 代码粘贴→即时风险检测（删除/网络/敏感API调用标注）（必须有）
2. 风险等级评分+可视化报告（必须有）
3. 代码沙盒模拟执行摘要（安全/危险操作列表）（必须有）
4. 多语言支持（JS/Python/Bash/SQL）（可选）
5. 历史检测记录+对比（可选）

## 变现设计
- 变现方式：增值服务
- 免费功能：每次500行代码检测 + 基础风险报告
- 付费功能：无限检测、CI/CD集成API、团队共享、企业私有部署
- 定价策略：个人免费/Pro ¥39月/Team ¥199月

## 技术方案
- 目标平台：Web
- 前端框架：HTML + CSS + Vanilla JS（纯静态）
- 后端方案：纯前端无需后端（AST解析前端实现）
- 数据存储：localStorage（检测历史）
- 第三方依赖：无付费依赖
- 部署方式：GitHub Pages
